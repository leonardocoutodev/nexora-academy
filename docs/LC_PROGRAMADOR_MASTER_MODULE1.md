## Objetivo do módulo

Construir uma base profissional de raciocínio computacional antes das linguagens do curso, cobrindo modelagem de problemas, dados, expressões, decisões, repetição, decomposição, estruturas de dados, teste, depuração e transição de pseudocódigo para código.

Este módulo não replica o curso separado **Lógica de Programação Básica** da LC. A trilha do Programador Master é deliberadamente mais condensada, integrada e orientada à progressão para desenvolvimento profissional.
