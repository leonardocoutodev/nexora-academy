# Release consolidada — UX, conteúdo e materiais

Esta release agrupa em uma única evolução coerente as mudanças de experiência mobile, profundidade das aulas, apostilas digitais, materiais de apoio, revisão editorial, contribuição voluntária e posicionamento de autoria.

A estratégia de versionamento da LC evita registrar microajustes de documentação como releases independentes. O Git continua preservando rastreabilidade técnica, mas alterações relacionadas são consolidadas antes de chegar à branch principal.
