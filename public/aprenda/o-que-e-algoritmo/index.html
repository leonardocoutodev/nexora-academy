O que é algoritmo? Entenda antes de programar

Entenda o que é um algoritmo, como identificar entrada, regra e saída e por que isso vem antes da sintaxe.

Algoritmo é uma sequência verificável

Um algoritmo é uma sequência organizada de passos criada para transformar uma entrada em um resultado. A ideia parece simples, mas ela separa “ter uma intenção” de “descrever uma solução que outra pessoa ou uma máquina consegue executar”. Se uma loja precisa calcular desconto, por exemplo, o problema ainda não está resolvido quando alguém diz “aplique a promoção”. É preciso saber qual valor entra, qual regra decide o desconto e qual total deve sair.

Entrada, processamento e saída

Uma forma prática de analisar um algoritmo é procurar três partes. Entrada é o dado necessário para começar. Processamento é a regra aplicada a esse dado. Saída é o resultado observável. Para uma compra de R$ 150 com desconto de 10% acima de R$ 100, a entrada é 150, o processamento compara o valor e calcula o desconto, e a saída esperada é 135.

Algoritmo não é linguagem de programação

Python, JavaScript e Java usam sintaxes diferentes, mas podem implementar a mesma lógica. Por isso, decorar comandos não substitui raciocínio. Primeiro vem a solução: quais dados existem, quais decisões precisam ocorrer, o que deve repetir e como conferir o resultado. Depois escolhemos a linguagem para escrever essa solução.

Como praticar

Pegue tarefas comuns e escreva os passos sem código: calcular média, aprovar um cadastro, verificar estoque ou ordenar atendimentos. Para cada caso, identifique dados de entrada, regras, exceções e saída esperada. Depois teste com exemplos simples e casos de fronteira. Esse exercício constrói a base que será reutilizada em qualquer linguagem.
