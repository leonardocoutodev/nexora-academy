O que é SQL e por que banco de dados importa

Entenda tabelas, chaves, relacionamentos, consultas, integridade, índices e transações em bancos relacionais.

SQL conversa com bancos relacionais

SQL é a linguagem usada para definir, consultar e modificar dados em muitos bancos relacionais. Em vez de pensar apenas em planilhas de linhas e colunas, pense em entidades com regras: usuários, pedidos e produtos têm identidade, relacionamentos e restrições.

Chaves e relacionamentos

Uma chave primária identifica uma linha. Uma chave estrangeira conecta entidades. Se um pedido pertence a um cliente, o banco pode garantir que o cliente referenciado realmente exista. Essa integridade evita uma classe de erros que seria difícil controlar apenas no frontend.

Consultas

SELECT recupera dados e pode combinar tabelas, filtrar, agrupar e ordenar. INSERT cria registros, UPDATE altera e DELETE remove. Em sistemas reais, o desafio não é memorizar esses quatro comandos, mas formular consultas corretas e entender o impacto das alterações.

Índices

Índices aceleram determinados padrões de consulta, mas têm custo de armazenamento e escrita. Criar índice em toda coluna não é estratégia. Primeiro observe consultas importantes, seletividade e planos de execução.

Transações

Quando várias mudanças precisam acontecer como uma única operação, transações ajudam a preservar consistência. Transferir saldo, criar pedido e atualizar estoque são exemplos em que falhar no meio pode deixar o sistema em estado inválido. Uma transação permite confirmar tudo ou desfazer tudo.
