Existem cursos realmente gratuitos?

Sim. O catálogo gratuito permanece disponível sem cobrança.

As formações profissionais são pagas?

Sim. Elas aparecem identificadas como formações pagas e o acesso depende de matrícula.

Preciso pagar para criar uma conta?

Não. A conta é gratuita e também serve para acessar os conteúdos gratuitos.

Comprar uma formação garante certificado?

Não. A matrícula libera acesso; a certificação depende dos critérios acadêmicos de conclusão.
