O que é programar

Diferenciar programação de linguagem de programação e reconhecer um programa como uma sequência precisa que recebe dados, aplica regras e produz um resultado observável.

22 minSem cadastro
STORY

Você já executa algoritmos sem perceber

Imagine que uma loja precise calcular o desconto de cada pedido. Uma pessoa poderia olhar o valor da compra, consultar a regra da promoção, calcular o desconto e informar o total. Um programa faz essencialmente a mesma coisa, com uma diferença decisiva: as instruções precisam ser suficientemente precisas para que uma máquina consiga executá-las sem perguntar o que você quis dizer.

É por isso que aprender programação não começa decorando comandos. Começa aprendendo a transformar uma intenção — “calcule o desconto” — em passos claros, dados identificáveis e um resultado que possa ser conferido.

CONCEPT

Programar é descrever uma solução executável

Programar é construir instruções para que um computador realize uma tarefa. Essas instruções podem receber dados, tomar decisões, repetir ações, fazer cálculos e produzir resultados. O código é a forma escrita dessa solução em uma linguagem de programação.

Python, JavaScript e Java são linguagens diferentes, mas a lógica pode ser a mesma. Se o problema é calcular a média de duas notas, qualquer linguagem precisará receber duas notas, somá-las, dividir o total por dois e apresentar o resultado. A sintaxe muda; a ideia permanece.

Essa distinção é importante porque um iniciante pode memorizar `if`, `for` ou `print` e ainda não saber resolver um problema. A competência central é conseguir explicar o que precisa acontecer antes de escolher os comandos.

Problema, algoritmo, linguagem e código não são a mesma coisa

  • Problema: calcular o valor final de uma compra com desconto.
  • Algoritmo: ler o valor, verificar a faixa de desconto, calcular e mostrar o total.
  • Linguagem: JavaScript, Python, Java ou outra.
  • Código: as instruções específicas escritas na linguagem escolhida.
EXAMPLE

Um programa antes do código

Considere a regra: compras de R$ 100 ou mais recebem 10% de desconto.

Entrada: valor da compra. Processamento: verificar se o valor é pelo menos 100; quando for, calcular 10% e subtrair do total. Saída: valor final.

Para uma compra de R$ 150, esperamos R$ 135. Para uma compra de R$ 80, esperamos R$ 80. Observe que já conseguimos discutir se a solução está correta sem escrever uma única linha de código.

PROFESSIONAL_CONTEXT

Por que profissionais começam pelo problema

Em projetos reais, o pedido quase nunca chega como código. Ele chega como necessidade: “bloqueie pedidos sem estoque”, “calcule comissão”, “ordene atendimentos por prioridade”. O trabalho de programação começa ao esclarecer dados, regras e resultado esperado. Quanto melhor essa etapa, menos retrabalho aparece depois.

Resumo

  • Programação é solução executável, não memorização de comandos.
  • Problema, algoritmo, linguagem e código representam etapas diferentes.
  • A mesma lógica pode ser implementada em linguagens diferentes.
  • Uma solução boa tem entrada, regra e resultado que possam ser conferidos.
